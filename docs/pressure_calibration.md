# 压力传感器标定实验

顶部选择“压力传感器标定”，默认“压力 · S1–S5 可选 · v2”。左侧“压力选通通道”控制采集板上的一路压力支路，五路共用 Nano A2；S1–S5 是电路网络名，与样品上五块油墨的物理位置仍需测通。默认 S3 与旧程序一致；下方“实际接线”只保存备注，不改变通道。

v2逐帧保存实际通道、ADC均值、名义原始电压、静置基线及ΔV。旧 `pressure_v1` 的固定 P2/S3 → A2 两列协议继续保留，不能通过修改接线文字实现切换。温度双路协议仍为 S6/S7 → A1 的顺序采样。本实验不需要 USRP，不控制丝杠。

## 固件、通道与手动置零

1. 初始化 Arduino USB 串口，选择压力 v2 和 S1–S5 中的一路，核对接线。旧压力程序不支持选择命令，首次使用须点击“烧录并验证”并确认目标板；已有v2可点击“验证已有固件”。选择界面选项本身不操作硬件。
2. 准备过程发送带本次令牌的选通命令，只有单片机确认同一通道、正确掩码、数字读回通过且连续输出匹配帧，才允许记录。重新打开采集串口可能让Nano复位，所以开始记录时再确认一次；验证阶段数据不混入实验。
3. 开始记录后松手静置，点击“静置后置零”。单片机平均未来40个有效帧建立V0；实际耗时受串口输出影响，须等界面显示基线完成。ΔV=V−V0，原始电压与ADC保留；未置零显示“未置零”，不伪造0。
4. “清除基线”取消旧V0。每次选通（即使仍选同一通道）、复位、重新初始化或故障均清除旧基线。同一run可在右侧选择S1–S5并点击“切换通道”。切换期间暂停计入有效样本，确认新通道后继续，原始字节与切换事件始终保存。每次选通使用新标识，数据和曲线按通道／选通标识分段，不把不同区块连续连接。基线不写EEPROM。
5. 标定区间内不能换通道或置零，先结束区间再切换，整场记录不必停止；置零／切换尚未结束也不能开始标定区间。区间参考力拟合仍基于原始电压，避免把置零操作误认为物理力标定。

采集中若收到错误通道、旧令牌、MCU复位、异常数据或选通故障，会停止接收并保留不完整记录；不会继续把读数标成原通道。TCA9555寄存器和输入读回只证明数字状态，不能替代测量Sk实际电压或证明材料接触正常。

## 现场操作

1. 固定样品与加载几何，使用独立参考测力设备读出法向接触力（N）。界面所填目标力只用于计划，不代替真实参考读数。
2. 选择实际接线的力敏通道、加载／卸载／保持方向、循环编号与参考仪器名称。接触面积只有在已知且可靠时填写，单位 mm²；未知则留空。
3. 加载到一个平台，待参考力与电压趋稳后开始标定区间。在区间开始、约中间及结束分别输入参考设备当时的实测力并记录。时间为点击时刻，不用目标力或时间插值生成参考值。
4. 结束区间并保存点，再进行下一个力平台。建议覆盖零载与多个有效载荷，并单独记录卸载及重复循环；安全载荷范围按实际样品与设备确定。
5. 完成后点击“停止并保存”。在本实验的“实验档案”中选择一条记录分析，或选择多条记录叠加展示；每条来源、加载方向与循环保留，不能视为一次连续实验。

只填写力时输出 N。存在明确接触面积时，平均接触压强按 `p_kPa = 1000 × F_N / A_mm²` 换算；这不是局部接触压强分布，也不能把未知或变化的面积视为固定已知面积。

## 保存与质量

v2的 `samples.csv` 额外保存 `baseline_v/delta_voltage_v/zero_id/baseline_ms/zero_count/selection_token`；未完成基线时留空，数值0与缺失分开。事件保存命令与选通确认，manifest绑定初始通道、实际采样通道集合、各次选通确认、固件准备与程序来源。历史详情可回看原始电压和手动ΔV，基线变化处断开ΔV曲线。

原始数据位于 `Data/temperature_pressure_runs/<run>/`，包括 `samples.csv`、`raw_serial.bin` 与串口事件。压力标定通过 manifest 中的 `pressure_calibration` 及 `calibration_points.json` 的 `sspp.pressure_plateaus.v1` 区分，不改写历史温度标定数据。

每个区间保留实际参考读数、目标力、所选通道、方向、循环、面积、参考仪器、起止时间、实际通道电压统计及质量标记。误差棒是区间内电压样本标准差（n−1），不是测力精度或置信区间。单样本不生成样本标准差。缺少参考、参考覆盖不足、不稳定、数据缺口、解析异常、MCU 复位、短区间等按实际数据标记；断连或停止时未结束的区间保留为中断，不伪装成完成。

参考判稳基于已记录的人工读数，无法证明读数之间没有变化。建议时长和默认门槛是可调整的实验参数，不是设备性能指标。

## 候选拟合与分析

至少三个不同力平台与电压均值、且通过数据质量门槛后，软件可生成 `F = aV + b` 的线性候选。只按同一记录、明确力敏通道、加载方向、循环、接触面积和参考仪器分组。中断、已删除、参考不足或有质量标记的点不参与候选拟合；有效点不足或退化时显示相应状态。

候选系数、样本内 RMSE、R²、参与点与实测范围保存在分析表中。它们是同一组拟合数据的描述，不是独立精度验证。软件不自动激活换算，不跨记录混合拟合，也不对范围之外外推。加载与卸载分开保留，避免用一条拟合线掩盖迟滞；重新装夹、不同温度或跨日重复应另行验证。

档案的参考力—电压图按来源、方向、循环、面积和仪器分组，保留各实测区间与样本 SD；明确面积的点另有平均压强—电压图。质量不足的观测仍可展示和复核。原始时间曲线始终保留全部实收通道电压，超过三秒的间隙或 MCU 分段断线显示。

## 修正与导出

完整封存后可在历史详情选择错误区间，填写原因后删除，或恢复已删除点。修正在绑定源文件哈希的 `Data/corrections/temperature_pressure_runs/<run>.json` 中保存，原始区间、采样和 manifest 不变；整个区间退出响应图及候选拟合，原始时间图保留。

“导出分析图与数据…”（单条）或“打包导出比较…”（多条）保存报告 PDF、图、CSV 表和来源哈希；在某张分析图上使用“导出分析图”可保存矢量 PDF／SVG、600 dpi PNG、图中数据、图注与来源清单至项目 `Figures/pressure_calibration/` 的新版本目录。图中没有参考值的点不补造。导出前后检查来源与修正账本；已生成报告的来源变化时需重新分析。

本功能通过离线合成记录验证，不表示真实压力传感器已经完成标定、迟滞评估或独立精度验收。

## 软件验证（2026-11-04，MacBook Pro M5 Max）

沿用既有 `rf-gnuradio` 环境，以模拟串口验证采集、封存与中断，以合成档案验证独立力值、面积换算、候选拟合、删除／恢复和来源保护；实际生成并检查 PDF、SVG 与 600 dpi PNG。离屏检查了新导航和标定表单。

广泛回归为 780 项通过、904 个子测试通过，4 项按原测试条件跳过。未纳入 `test_sweep_budget.py` 的原有文字断言失败与旧 `test_gap_and_point_timeout_abort` 的空起点错误：两者已在原仓库与暂存版本复现相同结果。另两个依赖完整历史数据的 UI 测试未在隔离暂存目录执行。最后增加单通道标识采集前校验后，压力及原温度采集专项 31 项通过。以上不代表全部原有测试无失败，也不代表真实传感器已标定。
