# SSPP 统一扫频实验

“材料扫频”“液体温度影响”和“SSPP 温度扫频”统一为顶部 **SSPP 扫频**。它们使用同一套扫频计划；样品条件、人工温度和连续温度记录按需选择，不再切换三个入口，也不需要先点击“应用条件”。

## 简洁参数面板与档案（2026-11-05追加）

采集流程从标题旁的“？”打开独立帮助弹窗，可按Esc或“关闭”退出，主界面布局保持。左侧将样品名称、传感器、温度记录方式和液体条件集中在“样品与条件”；扫频范围、轮次单列，高级参数按需展开。选择温度或液体时只显示相关输入，不需额外应用。

“实验档案”显示样品与条件摘要，选中一条可查看温度记录方式、真实参考温度、关联通道、液体、容器、体积和几何等已保存信息，并支持条件搜索。点选只读取摘要，勾选只更新分析选择；点击“查看已保存曲线”或回放才读取完整数据。搜索输入采用180ms合并刷新，同时立即废弃旧选择的异步结果。历史缺失项显示未记录；不会把当前待采集表单填进旧记录。

勾选记录后可用“删除所选…”批量删除，确认窗口显示名称和数量。失败或不完整记录也能清理；“已删除记录…”可选择恢复。删除将完整记录目录移到项目内的 `Data/.archive_trash/`，原始数据随记录保留，恢复时回到原路径；同名路径已存在时拒绝覆盖。采集或数据处理期间不能删除／恢复。已导出的图片、报告和训练结果独立保留。

勾选可用于删除或分析；分析仍只接受1–8条同类、符合封存条件的记录，液体记录使用专用温度比较入口。

## 从填写到开始

1. 打开实验台，在“初始化实验台”中检查本次使用的 B210。初始化就绪后，填写样品／条件名称和传感器说明。
2. 设置起止频率、频点数和轮数。桌面默认 5.0–5.3 GHz、30 个点、3 轮，RX 45 dB、首个单音 20000 Hz；单音步进 1000 Hz，因此 30 点对应 20–49 kHz。单点等待、弱点额外等待、基带单音及采样率／增益属于高级参数。首次启动和当前 SSPP 参数复位共用这组默认值；切换实验仍保留各自已填写的草稿。
3. 选择温度记录方式：不记录温度、手填平台实测温度，或 Arduino 连续温度电压。只有连续温度需要 Arduino；USB 初始化与温度协议验证均通过后才能开始。
4. 液体实验可展开液体条件，填写容器、体积、位置和参考温度等信息。输入直接用于本次启动，不再保留第二份“已应用”的旧条件。
5. 点击“开始扫频”。初始化通过后没有重复的接线确认勾选；缺少设备就绪、固件验证或有效参数时，界面说明缺少哪一步。
6. 记录结束后等待封存，再进入“实验档案”查看、分析和导出。

## 三种温度记录

| 方式 | 需要的设备 | 保存的温度证据 |
|---|---|---|
| 不记录温度 | B210 | 只有本次样品条件和 RF 数据，不填造温度 |
| 手填平台 | B210、操作者使用的参考温度计 | 本次人工实测温度；每个平台独立运行，不要求连接 Arduino |
| Arduino 连续记录 | B210、Arduino 与已经验证的温度固件 | S6/S7 原始电压、ADC及时间；选择其中一路与扫频关联。未标定时保持 V，不冒充 ℃ |

手填参考值和加热器目标值分开。连续记录与 RF 使用软件时间关联，不是硬件同步；每轮代表电压与轮内变化范围都保留。已有标定的换算需填写可追溯来源和有效范围，不能越界外推。

不记录温度和手填温度按指定轮数完成；Arduino连续电压方式持续循环。所有扫频都没有整场总时限；持续循环由“停止并保存”结束，单点质量检查、基础等待和弱点额外等待仍生效。更换材料、容器或装夹条件应另起记录，不能把不同条件混成一个标签。

## 初始化与确认

初始化状态绑定当前设备配置。更换 B210 配置或 USB 端口后，相应设备需要重新检查；另一设备的就绪状态保留。修改样品名、温度参考、扫频范围等实验参数不再要求重复勾选接线确认，开始前仍执行参数校验。

启动、刷新、选择温度方式与展开条件都不连接或启动硬件；必须显式初始化，再显式开始。Arduino 固件准备仍是独立步骤：初始化只证明端口可打开，协议验证证明可接收匹配数据。删除接线勾选不自动烧录，实际覆盖固件仍保留目标板与固件的烧录确认。

初始化、采集、保存和相关结果处理期间，配置与实验切换锁定；全局“停止并保存”继续可用。重新打开软件不会恢复上一窗口的设备就绪状态。

## 历史与固定频率实验

统一入口的档案同时显示原材料扫频、液体温度扫频和 SSPP 温度扫频。旧 manifest、原始 IQ、温度记录及修正账本保持原样；记录继续具有原来的情景类别，统一导航不代表不同协议／条件可直接相减。

液体固定频率／相位采集保留在固定频率实验中，液体条件为可选项；历史液体相位记录仍可查看和分析。液体与温度记录同时开启时，两组元数据都保留，不静默丢弃其中一组。

本次变更只验证软件交互、配置传递和档案兼容；没有启动 RF、打开真实串口、烧录或实施新实验。

## 设备通信失败

初始化成功不能证明随后流式发送必然成功。若出现发送接受0个样本，同时接收停止确认超时／EOB未确认，界面优先显示B210通信失响应及停止状态未确认，并取消该设备的就绪。先处理USB连接、集线器与供电，重新连接设备后显式初始化；不要靠增加弱点等待来处理通信异常。具体物理根因需现场复核，软件不自动重新发射。11月5日两次记录的核查见[失败诊断](startup_failure_20261105.md)。
