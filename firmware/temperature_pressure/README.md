# 温压实验固件包

本目录供多传感器实验台显式“烧录并验证”使用。软件启动、刷新端口和全局初始化均不烧录。当前板卡限定为先前实测的 **Arduino Nano / ATmega328P / Old Bootloader**；上传为 57600 波特，运行数据为 9600 波特。

| 实验模式 | 已有应用 HEX | 接线与输出 |
| --- | --- | --- |
| 压力 `pressure_v1` | `pressure_v1.hex` | TCA9555 P2 / S3，A2；`millis,电压` 两列 |
| 压力可选通道 `pressure_v2` | `pressure_v2.hex` | P0–P4 / S1–S5 单路可选，共用 A2；逐帧原始 ADC、电压、手动基线与 ΔV |
| 温度 `temperature_v1` | `temperature_v1.hex` | P5 / S6、P6 / S7 共用 A1，顺序采样；两组三列时间、ADC、电压 |

源码正本仍位于既有 `arduino-sensor` 仓库；本目录是与配套 HEX 共同分发的原字节副本，SHA-256 与来源保存在 `manifest.json`。本轮没有改动这两份算法、重新编译或实际烧录。温度 HEX 为 2026-09-07 编译、烧录、校验通过的 6484 字节应用。压力 HEX 为当天完整 Flash 备份提取的 30720 字节应用区（包含原尾部内容），不是本轮重新编译的产物，亦不包含 bootloader。

准备流程先校验包文件，再检查现有 avrdude 能否启动；读取 `1e950f` 芯片签名和完整 32768 字节 Flash 备份成功后，才写入所选应用并校验。不会使用 `-F` 绕过芯片签名，也不会写入 EEPROM、熔丝或 bootloader。写入期间请求取消，将等待当前写入和校验结束；此时请勿拔线。进程异常、超时或写入校验失败，必须重新烧录并验证后才能采集。

每次准备的备份、应用镜像、工具日志、串口验证字节及来源哈希保存于 `Data/device_preparations/<时间>/`，与正式实验记录分开。**完整 `flash_before.bin` 包含 bootloader，不应直接作为普通应用烧录文件**；恢复操作须先按原板卡应用边界提取并核验，不自动回写。

烧录后仍须接收到至少三个完整、连续且 MCU 时间递增的数据帧才会就绪。验证已有固件只证明输出协议；不读取程序身份，也不把本目录 HEX 哈希写成板上当前固件哈希。协议通过不意味着电压已换算为真实温度／压力，也不能替代传感器标定。

## 可选压力程序 v2（2026-11-04）

`Pressure_Diagnostic_v2.ino` 是 `arduino-sensor` 新版独立诊断程序的分发快照；`pressure_v2_build.json` 记录原生 AVR 构建命令及来源。程序占用 13176 字节 Flash、566 字节静态 RAM，不包括运行时栈峰值。软件模拟和协议联验已完成，**本版尚未烧录到实物或完成实物选通验收**。不能把旧两份固件的历史实测状态继承给 v2。

实验台选择 S1–S5 后先发送带随机会话令牌的 `SELECT`，核对单片机回报的通道、单 bit 掩码、A2 与数字寄存器验证，再验证至少三个递增帧。正式采集重新打开端口后重新握手，排除上次连接残留数据。每次重试使用新令牌；匹配最后一次确认前的样本只保留原始字节，不归到当前通道。数字状态确认不能代替测量实体 S 节点或识别实际油墨位置。

`Z <token>` 在未来 40 个有效帧上建立静置基线，`C <token>` 清除；两者由拥有串口的同一后台线程发送，不能在标定区间中执行。每帧包含 `P,t_ms,Sk,adc_mean,V,V0,dV,zero_id,baseline_ms,zero_count,token`，`NA` 表示无有效基线。ADC仍按名义5 V换算，原始 V 不扣基线。固件最短帧间隔100 ms，40帧置零至少约4秒，串口输出、诊断及硬件实际时序可能增加耗时。

旧 `pressure_v1` 仍可读取历史固定 S3 的数据；它没有运行时选通能力，选择该协议不会发送选通或置零命令。

采集中也可以显式切换 S1–S5，无需停止整个记录；应先结束当前力值标定区间，且等待置零／清除操作完成。每次切换重新发送带新令牌的 SELECT，先清基线、全断开再单路选通，确认前的旧帧只留原始日志。确认后继续记录，按逐帧通道和令牌区分区段；实时稳定窗口重新累计。返回同一通道也需重新置零，不能把上次基线带过来。最终 manifest 保存实际取得样本的通道集合、初始通道及每次成功确认历史；标定区间只允许使用当前确认通道。
