# 论文图片库

这是多传感器实验台的标准图片出口。各分析图页点击 **导出分析图**，自动生成 PDF、SVG、600 dpi PNG，以及绘图数据、图注和来源清单；点击 **打开图片文件夹** 可直接访问本次输出。

| 文件夹 | 实验 |
| --- | --- |
| `material_sweep/` | 材料扫频 |
| `finger_displacement/` | 手指位移、历史连续幅相 |
| `liquid_temperature/` | 液体温度影响（扫频／固定载频） |
| `temperature_pressure/` | 温压采集 |
| `temperature_calibration/` | 温度标定 |
| `temperature_sweep/` | SSPP 温度扫频 |

每类实验内部继续按 **记录 ID（组合分析为 combined_来源集合哈希）／导出时间与唯一版本号** 分层。重复导出保留所有旧版本；文件名使用稳定的图表 ID。这里仅存派生图，不存原始采样，不改变 `Data/`。

每个版本包含：

- `<图表ID>.pdf`：优先用于论文排版，文字和曲线保持矢量。
- `<图表ID>.svg`：用于矢量编辑、组图，字体需在编辑机可用。
- `<图表ID>.png`：600 dpi、白色背景的位图。
- `data.csv`：该图显示的数值、缺失值、误差棒及可用的逐点来源。
- `caption.txt`：图注草稿、统计含义和来源信息。
- `figure_manifest.json`：来源文件与代码哈希、图表标识、修正排除信息、导出产物哈希。

推荐连同数据和清单保存论文所用版本。**另存为…** 可以单独保存当前 PDF／SVG／PNG 到自选位置；正式可追溯版本优先使用默认导出。

输出文件被 Git 忽略，写论文时请自行备份／归档；只有本说明纳入代码版本。完整工作流与绘图规格见 [统一论文图功能](../docs/publication_figures.md)。
